# Dependency-Aware Network Isolation

This module develops dependency-Aware Network Isolation. It connects the intended application behavior to declared resources and observed conditions.

## Learning Goals

- Explain DNS lookup and Service discovery dependencies.
- Distinguish name resolution from backend connectivity.
- Identify required traffic under restrictive egress.
- Diagnose address, listener and policy failures separately.

## Before You Start

Examples describe system behavior. No runtime is required. Read each field or diagnostic name as part of the stated contract.
