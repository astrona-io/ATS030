# Troubleshooting A Service Request

This module develops troubleshooting A Service Request. It connects the intended application behavior to declared resources and observed conditions.

## Learning Goals

- Trace a client request through discovery and Service routing.
- Distinguish selector, readiness and port failures.
- Evaluate policy and dependency effects on reachability.
- Choose a correction supported by the first failed relationship.

## Before You Start

Examples describe system behavior. No runtime is required. Read each field or diagnostic name as part of the stated contract.
