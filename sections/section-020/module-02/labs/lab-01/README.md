# Repair A Service Target Port

Repair an internal Service while preserving its application replicas, selector and client-facing port. This independent graded environment starts with an intentional fault. It is separate from the ungraded module playground.

The task measures diagnosis and correction of backend port mapping. Its checks inspect the required resource fields and make a request from the client Pod. All content remains draft until review.
