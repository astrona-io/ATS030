# Get Your Machine Ready

A Markdown reader or the Astrona reading interface is enough for this course. Mermaid diagrams describe component relationships; the surrounding text explains the same mechanism if a reader cannot render a diagram.

No Kubernetes cluster, container engine, cloud account or installed command-line tool is required. Resource fields and command names are explained as descriptive examples. You are not asked to execute changes. There are no new labs or playgrounds.

Record unfamiliar terms and the reason for each practice answer. If a page fails to load, report its title and visible error so maintainers can locate the affected content.
