# External Request Diagnosis

This module develops external Request Diagnosis. It connects the intended application behavior to declared resources and observed conditions.

## Learning Goals

- Distinguish lookup, transport, routing and application errors.
- Identify whether the controller or backend produced a response.
- Evaluate endpoint readiness, ports and applicable traffic policy.
- Verify the intended host, path and secure application response.

## Before You Start

Examples describe system behavior. No runtime is required. Read each field or diagnostic name as part of the stated contract.
