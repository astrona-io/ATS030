# Ingress Routing And TLS Contracts

This module develops ingress Routing And TLS Contracts. It connects the intended application behavior to declared resources and observed conditions.

## Learning Goals

- Identify IngressClass and controller responsibility.
- Compare exact, prefix and implementation-specific paths.
- Trace host and Service port matching.
- Explain TLS termination and backend protocol limits.

## Before You Start

Examples describe system behavior. No runtime is required. Read each field or diagnostic name as part of the stated contract.
